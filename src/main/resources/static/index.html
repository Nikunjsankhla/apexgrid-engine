About ApexGrid Engine

Architectural blueprint and tournament validation specifications

1. System Architecture

Built with Java 17 and Spring Boot on the backend, interacting directly with MySQL 8.0 over Spring Data JPA. Serves responsive client assets without heavy frontend framework runtimes.

Interactive endpoints and schema contracts are documented via OpenAPI 3.1 & Swagger UI at /swagger-ui/index.html.

2. Core Match Invariants

  • Draw Prevention: Single-elimination formats require an outright winner; tie submissions are rejected.
  • Non-Negative Guards: Negative integers are rejected before reaching database persistence.
  • Deterministic Advancement: Advancing rounds update both upstream winners and downstream brackets.

3. Relational Schema

Uses four normalized entity tables: tournaments, teams, players, and matches (MatchFixture).

4. Getting Started

Select any game tournament using the dropdown in the Tournaments view, register an account, and enter match scores to observe live winner progression and standings updates.
